# findings/

Approved conclusions live here. A finding is recorded only after the full
methodology (docs/METHODOLOGY.md) is satisfied.

## Evidence grading (repeat of METHODOLOGY)

| Class | Meaning |
|---|---|
| 4 | Unexplained after all checks; consistent across independent images |
| 3 | Candidate; survives artifact checks, single image/angle only |
| 2 | Weak candidate; artifact not fully excluded |
| 1 | Explained artifact or geometry |
| 0 | Hoax / retouched / misattributed |

## Workflow
1. Copy `templates/finding_template.md` into `findings/` with a unique ID (e.g. `F-0001`).
2. Fill every section; the artifact checklist must be completed, not skipped.
3. Attach supporting images/crops in `findings/F-0001/` (originals, enhanced, annotated, controls).
4. Add the finding to this index with its class and status.
