How this EXE is built

    
Single-file EXE bundles FastAPI server + pipeline + dashboard + showcase + configs. No install needed — double-click nasa-fullstack.exe and the dashboard opens at http://127.0.0.1:8000. Data lives next to the EXE in data/.

    

      python scripts/build_app.py --fullstack
      dist/nasa-fullstack/nasa-fullstack.exe
      --onefile → dist/nasa-fullstack.exe
    

  


  
Full-stack build: app/server.py (FastAPI) + app/launcher.py + app/static — PyInstaller spec packaging/nasa-fullstack.spec — open legacy showcase · API docs
