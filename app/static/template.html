How this EXE is built

    
Single-file EXE bundles FastAPI server + AI engine + pipeline + dashboard + showcase + configs. No install needed — double-click nasa-fullstack.exe and the dashboard opens at http://127.0.0.1:8000. Data lives next to the EXE in data/.

    

      python scripts/build_app.py --fullstack
      dist/nasa-fullstack/nasa-fullstack.exe
      --onefile → dist/nasa-fullstack.exe
